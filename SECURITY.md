# Security Policy

Screenlogger stores screenshots and recognized text. Treat vulnerabilities that
could expose, corrupt, or silently broaden access to a Library as security
issues.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory flow for this repository:

1. Open the repository's Security tab.
2. Choose Advisories.
3. Choose Report a vulnerability.

Include affected versions, reproduction steps, expected impact, and any relevant
logs with private content removed. Do not attach a real Screenlogger Library or
captured screenshots.

## Supported versions

Until the first stable release, only the newest prerelease is supported. Security
fixes may require installing a newer build and granting macOS permissions again.
